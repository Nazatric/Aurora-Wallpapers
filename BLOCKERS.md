## Provider research and live checks

- Openverse's API reference supports anonymous requests for most use; registered OAuth clients receive higher limits. Auroro sends no credentials, maintains a local request window, observes provider rate headers, and pages incrementally. The official `GET /v1/images/` endpoint was checked without an authorization header. References: <https://api.openverse.org/v1/> and <https://docs.openverse.org/api/reference/authentication_and_throttling.html>.
- Wallhaven's official API documents ratio tokens but does not specify their exact boundary tolerance. A public `ratios=21x9` response included 3440×1440 (43:18, within Auroro's default 3% relative tolerance of 21:9); returned dimensions are also checked locally. Reference: <https://wallhaven.cc/help/api>.
