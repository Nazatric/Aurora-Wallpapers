## Live sources and rights

- This workspace's outbound network is restricted and cannot directly reach provider API/media hosts. A hosted Android-emulator run did reach some provider search endpoints, but its UI smoke stopped early; that partial run does not validate every source, query, media URL, or rights path.
- Wallhaven uses its official API with source-side `purity=100`. The hosted emulator logs included Wallhaven result rows accepted by the source/dimension checks. The app has no global SFW/NSFW preference, hidden keyword/tag rejection, or category rejection. Broader query, image-fetch, and rate-limit behavior still needs validation.
- NASA APOD now uses the migrated WordPress-backed endpoint `https://science.nasa.gov/wp-json/wp/v2/apod-basic` (the app's `NasaApodApi` targets it directly; `hdurl` is treated as the real media URL because `url` is an article link). A live response was verified on **2026-10-12** with real current-day content (`post_id`, `date`, `title`, `media_type`, `hdurl` on `assets.science.nasa.gov`, `credit`/`copyright`) rather than the placeholder responses reported for the legacy endpoint. The legacy `api.nasa.gov/planetary/apod` service is archived on **2026-12-01** and the app does not depend on it. APOD still does not provide authoritative pixel dimensions; rendition URL parameters are not treated as image measurements, and unknown dimensions remain unknown. Credit/copyright fields do not establish reuse rights: APOD remains browse-only, with download and wallpaper setting disabled.
- Art Institute search was reached in the hosted run and returned records, but the captured sample had unknown `0x0` dimensions and zero size-usable items. Six source-specific query mappings are configured, with one museum query per For You mix; only records marked public domain with an image ID are accepted. IIIF metadata, media loads, rate behavior, dimensions, and availability still need validation.
- Reddit remains paused until authorized official OAuth access is configured; no scraping, client impersonation, or access-limit bypass is used. Pixabay permission/terms for wallpaper-file use remain unverified and it is not integrated. Lorem Picsum is omitted. Unsplash is not integrated: its current API guidelines (verified 2026-10-12) explicitly exclude wallpaper applications from replicating the Unsplash experience, and `source.unsplash.com/random` is retired; no unauthorized integration or dead endpoint is shipped, and the approval/exception route is documented in the README.
- Openverse is removed from active provider/query use. Saved legacy metadata and existing local files remain readable; new retired-source previews, downloads, and remote wallpaper preparation are blocked.
