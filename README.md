# Auroro Wallpapers

**Work in progress.**

The application UI is being rebuilt from scratch, one slice at a time, on top of the validated Kotlin data/domain layer (providers, discovery and validation engines, Room/DataStore persistence, settings, download/apply pipeline).

**Slices 1–7 are in:** dark-first Material 3 shell with a floating pill navigation bar whose selection indicator is a single sliding spring pill; Home feed with mode chips (For you / Trending / Newest / Random, each mapped to a real catalogue sort), an icon-only Any/Portrait/Landscape orientation filter in the header, and three Settings-driven layouts (stacked cards with hero pager, two-column grid, compact list). Cards show whole artwork (`ContentScale.Fit`) in containers that snap to each decoded image's REAL aspect, so bars and strips are gone even when CDN frames disagree with metadata; pull-to-refresh and double-tap-Home refresh the mix; previews are full originals decoded through a 2560 px cap for speed without softness; fullscreen detail with Favorite / Share / Download / Info circles, a big Set-wallpaper button, HDR window colour mode on HDR-capable displays, and honest whole-image preview; a crop editor with rule-of-thirds grid, 90° rotation (the applier maps the rotated rect back onto original pixels and rotates only the cropped region), and Home/Lock/Both icon cards; search with debounced `FeedPager` queries and a staggered grid; a cover-flow showcase with an icon-only All/Portrait/Landscape orientation filter; Library with Favorites, Downloads (All/Completed/Failed filter chips, live progress, retry/cancel/delete) and a real viewing History; and Settings that actually re-theme the app live — theme mode (light/dark/system), design presets, accent hue, AMOLED, contrast boost and font scale all route through a composition-local palette, and the Liquid Glass theme (slice 7): one backdrop engine — Haze 2.0.1 stable — behind a shared `auroroGlass`/`auroroHazeSource` abstraction, giving the pill bar, floating icon buttons and segmented controls real captured-backdrop glass (refraction tier, frosted tier, or opaque reduced tier per the now-functional Glass quality setting) with automatic fallback on unsupported devices; only the typeface swap remains a later slice. Wallhaven cards/carousels load the large thumb instead of the 4K original, APOD previews cap at 1440 px, detail/apply always use the original. Motion follows Material 3 Expressive guidance (bouncy springs for small elements, emphasized easings for surfaces).
